What's included

Reloop Resale is a from-scratch Shopify theme purpose-built for stores that resell goods — thrifted, pre-loved, refurbished, surplus, or trade-in inventory — rather than sell new stock from a single brand. It's built on Shopify's standard Online Store 2.0 architecture: JSON templates and Liquid sections/blocks, so every part of every page is customizable from the theme editor with no code required.

Resale-specific features

  • Condition badges (New / Like New / Good / Fair)
  • Authenticity guarantee badge & info tab
  • "One of a kind" sold-out messaging
  • Automatic "Save X%" vs. retail price
  • "Sell with us" trade-in / consignment section
  • "How it works" step explainer
  • Trust badges, testimonials, brand marquee

Store essentials

  • 4 built-in color presets, switchable in one click
  • AJAX cart (drawer or page), no cart app needed
  • Responsive, mobile-first layout
  • WCAG AA-checked color contrast on every preset
  • No build step, no framework — plain Liquid/CSS/JS
  • shopify theme check clean (0 offenses)

Installation

Option A — Upload via Shopify Admin (no CLI needed)

  1. In Shopify Admin, go to Online Store → Themes.
  2. Click Add theme → Upload zip file.
  3. Select the theme zip included in this download.
  4. Once uploaded, click Actions → Preview to check it before publishing.

Option B — Shopify CLI (for developers)

shopify theme dev --store your-store.myshopify.com   # live local preview
shopify theme push --store your-store.myshopify.com   # upload as a new theme
Always install onto a duplicate or unpublished theme first, preview it, and only Publish once you're happy — this never touches your live storefront until you choose to.

Quick start

  1. Open the theme editor: theme card → Customize.
  2. Pick a color preset under Theme settings → Colors (see Color presets).
  3. Upload your logo under Theme settings → Logo.
  4. Fill in Theme settings → Resale settings — authenticity badge text, the "Sell with us" link, condition badge toggle.
  5. Build your Main menu and Footer menu under Online Store → Navigation.
  6. Tag your products with condition:<value> (see Condition badges).
  7. Preview on mobile using the toggle at the top of the theme editor, then Publish.

Condition badges

Mark a product's condition one of two ways — the theme checks both automatically:

  1. Product tag — add a tag like condition:like-new (also: new, good, fair, deadstock).
  2. Metafield — a custom.condition text metafield, for stores managing condition at scale.

The matching badge then renders automatically on product cards, the product page, and cart line items. Colors/labels are editable under Theme settings, and badges can be turned off entirely.

Theme structure

layout/theme.liquid          Base HTML shell
config/settings_schema.json  Theme editor settings
config/settings_data.json    Default values + presets
locales/en.default.json      UI strings
sections/                    Page sections (editable in theme editor)
snippets/                    Reusable Liquid partials
templates/                   JSON templates (home, product, collection, cart, ...)
assets/                      CSS + JS (no build step, no framework)

Customizing sections

Every homepage section — hero banner, trust badges, featured collection, how it works, brand marquee, sell-with-us, testimonials, newsletter — can be added, removed, reordered, or hidden from the theme editor. Blocks inside a section (e.g. individual trust badges or testimonials) work the same way. No code changes are required for everyday content edits; developers extending the theme's Liquid can find each section's file under sections/, named to match what's shown in the editor.

FAQ

Do I need any apps for the cart or badges to work?

No — cart (drawer or page), condition badges, and trust badges are all built into the theme itself.

Can I use my own categories?

Yes — the theme has no hardcoded categories. Create Collections in Shopify Admin for whatever categories fit your inventory (Fashion, Electronics, Home, Art, etc.) and add them to your navigation.

Does it support blog or customer account pages?

The current version covers home, collection, product, cart, page, and search templates. Blog, article, and customer-account pages fall back to a generic layout until custom templates are added in a future update.

Will it slow my store down?

No build step, no external frameworks, no jQuery — just hand-written CSS/JS and Shopify's native responsive image and cart APIs.
