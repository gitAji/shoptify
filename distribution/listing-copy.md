resale, thrift, refurbished, and trade-in stores. Unlike generic themes

## Full description

**Why a resale-specific theme?**
Generic Shopify themes assume new, infinite-stock, single-price inventory.
Resale businesses don't work that way — items are often one-of-a-kind,
buyers care about condition, trust matters more than usual, and many
resale stores also *buy* from customers. Reloop Resale builds all of that
in natively.

**Features**
- Condition badges (New / Like New / Good / Fair) from a product tag or metafield
- Authenticity guarantee badge + accordion tab on every product
- "One of a kind" messaging when a single-variant item sells out
- Automatic "Save X%" badge whenever a compare-at price is set
- "Sell with us" trade-in/consignment section + page link
- "How it works" 4-step explainer section
- Trust badges, testimonials, and a scrolling brand marquee
- 4 built-in color presets (Blush Bloom, Forest Canopy, Slate Market, Terracotta Bazaar), switchable in one click
- AJAX cart — drawer or full page, no cart app required
- Fully responsive, mobile-first
- Built on Shopify Online Store 2.0 — JSON templates, sections & blocks throughout
- WCAG AA color-contrast verified on every preset
- `shopify theme check` clean — 0 offenses
- No build step, no framework — hand-written Liquid/CSS/JS

**What's included**
- Full theme source (installable via zip upload or Shopify CLI)
- Documentation (`documentation.html`) with setup, customization, and FAQ
- License terms (`LICENSE.md`)
